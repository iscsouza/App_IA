## 🌟 Sobre o Projeto

O **Pro Salário** nasceu de uma iniciativa prática de capacitação voltada para estudantes e entusiastas de tecnologia, explorando o potencial das ferramentas de **Inteligência Artificial (IA)** como co-pilotos no processo de desenvolvimento de software e geração de aplicativos móveis (APK).

O objetivo principal desta atividade extensionista foi demonstrar como a IA pode transformar ideias em aplicações funcionais, modernas e prontas para o mercado, unindo design humanizado, arquitetura limpa em Flutter e lógica financeira em tempo real.

---

## 🎯 Objetivo da Capacitação e Extensão

- **Empoderamento Tecnológico:** Capacitar alunos a utilizarem IA generativa e assistentes de código para conceber, estruturar e finalizar projetos de software.
- **Ciclo Completo de Desenvolvimento:** Do planejamento inicial à compilação e teste do APK multiplataforma.
- **Impacto Social e Educacional:** Aproximar a comunidade acadêmica das ferramentas modernas de desenvolvimento mobile, estimulando a inovação e a resolução de problemas reais.

---

## ✨ Funcionalidades do Aplicativo

- **⏱️ Acumulado em Tempo Real:** Acompanhe o crescimento do seu salário segundo a segundo, calculado com base nos dias úteis e jornada de trabalho (8h/dia).
- **📊 Progresso Mensal:** Barra de progresso inteligente que reflete o avanço do mês considerando apenas os dias úteis.
- **💼 Detalhamento Prático:** Visualização imediata do valor gerado por dia útil e por hora de trabalho.
- **✏️ Personalização Fácil:** Altere seu salário mensal a qualquer momento através de um painel intuitivo com persistência local (`SharedPreferences`).
- **🌙 Design Moderno (Dark Mode):** Interface elegante inspirada em padrões de mercado, desenvolvida em Flutter com Material 3 e paleta de cores refinada.

## 🚀 Como Executar o Projeto

Se você deseja explorar o código ou gerar sua própria versão do APK, siga os passos abaixo:

### Pré-requisitos
- Ter o [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado em sua máquina.
- Um emulador Android/iOS configurado ou um dispositivo físico conectado.

### Instalação e Execução

1. Clone o repositório:
   ```bash
   git clone https://github.com/iscsouza/App_IA.git
   cd App_IA
   ```

2. Instale as dependências:
   ```bash
   flutter pub get
   ```

3. Execute o aplicativo:
   ```bash
   flutter run
   ```

### 📦 Como Gerar o APK de Produção (Leve e Otimizado)

Para gerar um APK otimizado e compatível com a maioria dos dispositivos Android do mercado (`--split-per-abi`), execute:

```bash
flutter build apk --release --split-per-abi
```

Os APKs gerados estarão disponíveis na pasta:
`build/app/outputs/flutter-apk/`
